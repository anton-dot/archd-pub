# ArkiBoard

Офлайн-редактор архитектуры программных систем на Flutter.

**Веб-приложение: [draw.kurakin.pro](https://draw.kurakin.pro/).**

## Возможности

- Несколько схем в проекте, переходы между контекстом системы, контейнерами и компонентами.
- Архитектурные компоненты, базы данных, очереди и топики, наблюдаемость, безопасность.
- Быстрое добавление со связью через «+», поиск компонентов и редактирование названий на холсте.
- Кнопки сворачивания левой и правой панелей, возврат по краям холста и сохранение выбранного состояния.
- Холст автоматически расширяется во все стороны, включая влево и вверх: карточки, группы, фрагменты и точки стрелок можно размещать за пределами исходного листа. Расширение сохраняет координаты соседних элементов и камеру; мини-карта и экспорт учитывают отрицательные позиции.
- Перемещение, масштабирование, изменение размеров, множественное выделение, выравнивание и автокомпоновка.
- Вложенные группы, копирование и дублирование с содержимым, Undo/Redo.
- Сворачивание контейнеров с сохранением размера и положения рамки: название в заголовке, область ответственности по центру, число скрытых элементов и внешние связи.
- Полноэкранное редактирование внутри исходной рамки группы: входы слева, выходы справа; двусторонний внешний компонент показан с двух сторон как один объект модели. Добавление, свойства, перемещение, связи и Undo/Redo.
- Плавные переходы контейнеров: детали исчезают на месте, описание появляется следующим этапом; стрелки меняют маршрут через затухание без промежуточных диагоналей. Быстрое обратное переключение и системное отключение анимаций.
- Личная библиотека фрагментов с вложенностью, настройками, пояснениями и внутренними связями; вставка в любой проект одним Undo.
- Исследование входящих и исходящих зависимостей на глубину 1–3 и поиск кратчайшего пути между компонентами.
- Умные направляющие: выравнивание, равные интервалы, подсветка группы назначения и временное отключение привязки через Alt / ⌥.
- Подсветка соседей и связей при наведении, закрепляемый фокус без изменения обычного выделения.
- Синхронные, асинхронные и двунаправленные связи; стороны подключения, ручные маршруты, цвета и отключаемые мостики пересечений.
- Стикеры и текстовые пояснения, описания компонентов при наведении.
- Ссылка на описание компонента в свойствах: Wiki, README или API-документация, открытие в браузере, синхронизация между схемами и перенос в проекте и экспортах Markdown/HTML.
- Системные настройки по типу компонента: реплики, отказоустойчивость, партиции, ключ партиционирования и другие параметры.
- Общая модель компонентов и представления на разных схемах.
- Требования, допущения, архитектурные решения (ADR), риски и расчёты нагрузки.
- Сценарии взаимодействий и анимация потока: явные последовательные и параллельные этапы, пауза, скорость до 10× и повтор.
- Локальная проверка архитектуры с пояснениями замечаний и разбором зависимостей при отказе.
- Примеры архитектур на главном экране свёрнуты по умолчанию: заголовок с количеством примеров раскрывает поиск, фильтры и карточки Outbox/Inbox; фильтры сохраняются при сворачивании. Готовые фрагменты Transactional Outbox и Inbox.
- Импорт и экспорт редактируемых проектов `.archd`; SVG, PNG, PDF, HTML и другие форматы для передачи результата.
- Импорт draw.io (включая сжатые страницы), PlantUML/C4, Mermaid, Markdown и HTML: готовые типовые элементы по названию, технологии и фигуре, внешние карточки для свободных концов стрелок, предпросмотр и необязательное ручное уточнение. Обычно достаточно нажать «Создать проект».
- Новые текстовые экспорты включают данные для обратного импорта в своём объёме; при изменении исходника можно выбрать сохранённую модель или видимый текст.
- Экспорт всех страниц в draw.io, схем в PlantUML и C4/PlantUML, сценариев в Mermaid sequenceDiagram.
- Документация Markdown со схемами Mermaid, описаниями, требованиями, ADR и расчётами.
- Самостоятельный HTML с офлайн-проигрывателем: этапы, параллельные действия, пауза, скорость до 10× и повтор.
- Светлая и тёмная темы, поиск по схеме, мини-карта и режим презентации.

## Хранение данных

Аккаунт и сервер приложению не нужны. Проекты автоматически сохраняются в `localStorage` текущего браузера. Они не синхронизируются между устройствами; очистка данных сайта удаляет локальные копии.

Для резервной копии и переноса используйте **«Выгрузить проект (.archd)»**. Кнопка **«Загрузить файл»** создаёт отдельный локальный проект и сохраняет остальные проекты.

Расчёты и проверки помогают рассуждать об архитектуре; они не заменяют нагрузочные испытания и не доказывают её корректность.

## Размещение

В этом репозитории находится готовая статическая веб-сборка. GitHub Pages публикует корень ветки `main`; файл `CNAME` задаёт домен `draw.kurakin.pro`, а `.nojekyll` отключает преобразование файлов Jekyll.

Ресурсы движка Flutter включены в сборку и загружаются с домена приложения. Готовую сборку можно также разместить на другом статическом HTTPS-хостинге.

Для обновления используйте релизный сборщик основного проекта: `dart run tool/build_web_release.dart`. Он создаёт уникальный ID, версионные URL и `release.json`. Переносите всё содержимое `build/web` в этот репозиторий, сохраняя `CNAME`, `.nojekyll` и этот README.

## Обновление приложения

Приложение проверяет новую версию при запуске, раз в пять минут и при возвращении во вкладку. Уведомление предлагает «Обновить» или «Позже». Перед перезагрузкой сохраняются проекты и незавершённое название на холсте; при ошибке сохранения обновление останавливается. Данные localStorage сохраняются. Уже открытые вкладки версии без проверки обновлений нужно один раз перезагрузить вручную.

Готовые компоненты доступны через **Компоненты → Из проекта** в левой палитре и **Из проекта** в меню добавления, включая «+» рядом с карточкой и телефон. Поиск по названию, технологии и описанию; добавление нажатием или перетаскиванием из палитры. Общий идентификатор и свойства компонента сохраняются между схемами, положение карточек независимо. Повторный выбор показывает существующую карточку; «+» соединяет с ней без дубликатов. Новое представление вместе со связью отменяется одним Undo.

Компоненты сгруппированы по типам в «Из проекта», с количеством элементов и сортировкой внутри типа по алфавиту. Группы в палитре можно сворачивать, поиск раскрывает подходящие группы; в меню добавления клавиатура пропускает заголовки.

Тип **Модуль** для внутреннего состава сервиса: бизнес-логика, обработчики команд, адаптеры и библиотеки. Отдельная иконка, описание ответственности, технология, связи, переиспользование между схемами и сохранение при импорте/экспорте. C4 экспортирует модули как Component. Формат проекта 15, старые проекты поддерживаются.
